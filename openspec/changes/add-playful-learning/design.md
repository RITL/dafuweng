# Design: 趣味学习与跨设备兼容

## Context

家庭会在手机横屏、平板、笔记本、电视浏览器和 Android TV WebView 上进行同一局游戏。棋盘本身已经能按视口重排，新增学习内容最主要的风险不是业务逻辑，而是弹窗、按钮和文字再次把短屏横屏挤坏。

## Goals

- 学习内容解释当前旅行或经营行为，不把游戏突然变成试卷。
- 每次互动尽量在 10–20 秒内完成，可跳过、可提示、答错不惩罚。
- 同一业务功能在主棋盘和 iPhone 遥控器上都有可完成路径。
- 每个新增浮层先按最矮手机横屏设计，再向大屏渐进增强。
- 新功能必须通过固定屏幕矩阵后才能标记完成。

## Non-Goals

- 不重做已经完成的实体俄罗斯轮盘。
- 不建立账号、云端同步、公开积分榜、连续签到或儿童画像。
- 不要求每个回合答题，也不以答题成绩改变核心资产冠军。
- 不在地图小格中增加英文名、百科段落或更多永久文字。
- 不在本变更中改写 Android TV 原生壳层。

## Learning Model

### Player profile

玩家继续使用 `isChild` 保持旧存档兼容，并新增可选年龄段：

- `4-6`: 数数、比较、颜色、图形和看图选择。
- `6-8`: 20/24 以内加减、国家与大洲、简单找零。
- `8-10`: 乘法、预算、距离估算和经营判断。
- `10+`: 百分比、收益比较、资源规划和概率启蒙。

未设置年龄段的小朋友沿用现有双球加法难度；成人默认不触发儿童题目。年龄只用于选择内容，不在排行榜展示或比较。

### City knowledge cards

城市配置使用独立学习字段，不把内容塞入地图格：国家、大洲、地标、一句短知识、英文名、可选当地问候语。首次到达该城市时可出现 10–20 秒知识卡；重复到达只显示简短收藏状态，避免拖慢节奏。

知识卡必须提供“知道了/继续”和“本局不再提示”入口。语音播报只读短句；长内容只能由玩家主动展开。

### Travel challenges

挑战在每 2–3 回合或指定特殊格低频触发。系统按当前玩家年龄和最近题型提供 2–3 个类别供选择，避免连续重复。挑战允许提示、查看答案和跳过；错误只触发鼓励与辅助，不扣钱、不停回合、不公开速度。

学习奖励与现金分离，使用本局印章、称号候选或家庭能量。奖励数据进入结算奖项，但不进入总资产。

### Family achievements

总资产冠军保持现有算法和视觉主位。其后追加非排他奖项，例如：

- 环球探索家：到达不同城市最多。
- 城市规划师：完成建设次数最多。
- 勇气之星：主动尝试挑战次数最多。
- 合作伙伴：参与家庭帮助或协作事件最多。
- 表达达人：完成语言或介绍类互动最多。

奖项允许多人并列；不得用奖项覆盖、降级或混淆资产冠军。

## Responsive Architecture

### Content hierarchy

新增浮层统一采用三层信息：一句标题、一个当前任务区、一排主操作。百科详情、解释和历史记录放入可展开区域。短屏时只保留完成当前动作所需内容。

### Presentation by device

- 桌面/电视：知识卡和挑战可作为棋盘中央安全区内弹层，外围 64 格仍保持可见。
- 手机直接玩：横屏使用紧凑弹层，宽度不越过安全区，高度不得产生页面级纵向滚动；必要时仅弹层内部滚动。
- iPhone 遥控：当前选择、答案和继续操作必须在手机端完成，不要求走回电视点击。
- 手机竖屏：主棋盘仍显示横屏提示；遥控器资产和必要控制可保持原有可用策略，不新增被困状态。
- 电视遥控器：每个新增弹层有明确初始焦点，方向键可达全部主操作，返回键关闭非强制说明。

### Required viewport matrix

每项功能至少验证：

- 844×390（iPhone 12 Pro 横屏）
- 896×414（iPhone XR 横屏）
- 932×430（较宽手机横屏）
- 768×1024 与 1024×768（平板双方向）
- 1280×800（Nest Hub Max/短桌面）
- 1366×768（笔记本/电视浏览器）
- 1920×1080（电视与桌面）
- 3840×2160（4K 整体缩放）

同时验证浏览器缩放 85%、100%、125% 中至少不会出现功能不可达；125% 主要覆盖开发者设备模拟和系统字体放大造成的空间压力。

### Layout invariants

- 不允许关键按钮被裁切、遮挡或落在视口外。
- 不允许选择控件退化成无间距连续文字；每个选项必须有边界、选中态和至少 44×44 CSS 像素触控区域。
- 不允许浮层覆盖手机横屏顶部玩家资产条或右上角功能入口后导致无法关闭。
- 不允许知识卡、题目或奖项改变棋盘业务坐标和移动顺序。
- 弹层关闭后恢复原焦点、滚动位置和回合阶段。
- 语音关闭、拒绝麦克风或远程断开时，所有流程仍能用按钮完成。
- 尊重安全区、减少动态效果和系统字体放大；文本可换行但不得与金额、倍率或按钮重叠。

## Rent Difficulty Control Readability

地产收费强度保留当前温和、标准、激烈、大亨四档及已有卡片视觉，不重新设计。仅适当增大名称、说明和倍率字号，并回归选中态、焦点态与移动端紧凑布局，确保文字清楚、内容不溢出且触控区域足够大。

## Persistence and Migration

新增字段全部可选并提供默认值。旧存档载入时：未设置年龄段的小朋友沿用当前加法规则；未设置学习统计时初始化为空；不存在知识卡记录时只从下一次合法触发开始，不追溯弹出大量卡片。

## Verification Strategy

- 单元测试覆盖年龄内容选择、触发频率、答错无经济惩罚、奖项并列和旧存档迁移。
- 组件/流程测试覆盖跳过、提示、关闭恢复、重复点击与语音降级。
- 视觉验收按固定矩阵逐项截图；发现任一关键操作不可达，则对应任务不得勾选完成。
- 回归实体轮盘、购买/升级/付租、资产弹窗、功能抽屉、结算和手机遥控连接生命周期。
