# Change: 增加自然融入对局的趣味学习功能

## Why

当前游戏已经完成实体/电子轮盘、城市经营、双球加法、语音主持、家庭援助、手机遥控和多端棋盘等核心体验，但儿童学习主要集中在固定的加法题，城市旅行内容、年龄差异和家庭协作还没有形成持续复玩的记忆点。

本变更将产品建议中的高价值功能分阶段接入现有对局，同时把屏幕兼容列为功能验收的硬条件。新功能不得挤压棋盘、遮挡操作、破坏手机遥控或只在单一桌面尺寸可用。

## Existing Capabilities Not Rebuilt

- 实体俄罗斯轮盘已经支持电子/实体模式切换、0–24 点录入、语音报点、0 点结果、防重复提交和偏好记忆。
- 城市购买前已经展示余额、租金等级和预计回本次数。
- 城市中文名与英文名已经支持语音播报，英文名不占地图格文字空间。
- 小朋友加法答错不会受罚，并已有多种鼓励文案和触控数字降级操作。
- 电视独立显示、iPhone 遥控、手机横屏棋盘和玩家资产查看已经存在。

上述能力只进行兼容回归，不作为本变更中的重复开发任务。

## What Changes

- 新增玩家年龄难度：以年龄段决定题型、数字范围、提示方式和交互复杂度；保留原“小朋友”开关并兼容旧存档。
- 新增城市知识卡：在合适的首次到达或收藏时，用短内容呈现国家、大洲、地标、问候语和趣味知识。
- 新增可选择的旅行挑战：数学、地理、语言、理财和观察类挑战以低频方式自然进入旅行流程，答错不影响核心经济与回合资格。
- 新增多维度结算奖项：在总资产冠军之外，表扬旅行、经营、勇气、合作和表达等不同表现。
- 修正地产收费强度选择器的视觉和响应式表现，使其在开始页和游戏功能区都保持清晰、可点击和一致。
- 为上述功能建立桌面、手机横屏、手机遥控、平板、电视和超大屏的强制兼容验收矩阵。

## Capabilities

### New Capabilities

- `playful-learning`: 年龄难度、城市知识卡、旅行挑战、非惩罚反馈和学习进度摘要。
- `family-achievements`: 多维度局内记录、结算奖项与共同成就展示。
- `cross-device-feature-compatibility`: 所有新增功能在棋盘端、手机遥控端和电视端的布局与交互验收标准。

### Modified Capabilities

- `family-game-session`: 玩家资料增加可选年龄段，并以兼容方式迁移旧存档。
- `world-city-board`: 城市首次到达可触发短知识内容，但不得增加地图格的信息密度。
- `instant-settlement`: 在原资产排名之后增加不改变胜负的多维度奖项。

## Impact

- 主要涉及玩家和对局类型、城市学习内容配置、挑战题库、对局事件统计、结算界面以及各端响应式样式。
- 所有数据继续保存于浏览器本机，不增加账号、云端儿童档案、公开排行或连续签到。
- 学习奖励原则上使用印章、称号或家庭能量，不通过大量现金改变经营公平。
- Android TV 继续复用正式网页，不新增原生业务逻辑；网页能力和适配验证通过后即可随页面更新获得功能。
