# Design: 家庭投屏大富翁

## Context

游戏主要在家庭聚会时由一台电脑、平板或手机打开并投到电视上，所有玩家围绕同一块屏幕轮流操作。体验重点不是严格复刻商业桌游，而是保留买城市、建设、收租和随机事件的乐趣，同时显著减少计算、找零和反复确认。

## Goals

- 一块屏幕即可完成整局游戏，不依赖纸币和人工记账。
- 轮到谁、当前位置、可执行动作和资金变化在电视上清晰可见。
- 语音主持能点名提醒，并允许玩家说“前进”或“等一等”。
- 随机事件有惊喜但不过度惩罚，儿童也能持续参与。
- 所有关键动作都可用鼠标、触控完成，语音只是增强而非前置条件。

## Non-Goals

- 不做在线多人房间、账号体系或云端存档。
- 不追求逐字逐项复制任何商业版规则、卡牌文案或受保护美术。
- 不依赖语音才能继续游戏。
- 第一版不做 AI 玩家和手机端遥控器。

## Core Flow

1. 家庭创建对局，选择 2–6 位玩家并填写名称；可为玩家标记“我是小朋友”。
2. 系统随机决定先手，镜头/高亮聚焦当前玩家并语音点名。
3. 玩家说“继续/前进”或点击“开始前进”，双球轮盘旋转；两颗球分别生成 0–12 的安全随机落点，相加得到 0–24 的本回合步数。
4. 成人玩家直接进入移动；小朋友玩家需观察轮盘并回答“这是多少点”，回答正确后才逐格移动。答错时只进行温和鼓励并继续等待，不公布答案、不惩罚、不跳过回合。
5. 根据落点进入购买、升级、付租、抽卡或特殊格处理。
6. 所有结算完成后，由玩家确认“结束回合”，系统点名下一位玩家。
7. 玩家可随时查看资产和日志；结束游戏时按现金加资产估值结算排名。

## Instant Settlement

- 家庭有事需要中止时，可从固定可见的“结算本局”入口随时发起结算。
- 为防止误触，结算前展示一次确认，并说明结算不会继续产生租金或卡牌效果。
- 如果棋子正在移动或一笔交易正在播放动画，系统先完成当前已确认的结算，再生成最终榜单。
- 总资产严格按原价计算：`当前现金 + 城市购买原价 + 已支付的全部房屋/旅馆升级原价`，不计算市场涨跌、未来租金或折旧。
- 排名先按总资产降序；同分时现金更多者在前；总资产与现金均相同则显示并列名次和共同冠军。
- 结算页展示每位玩家的现金、城市原价、建筑投入和总资产明细。
- 第一名使用全屏彩带、放大冠军卡和中文恭喜文案；尊重“减少动态效果”设置并提供立即跳过按钮。

## Voice Host State Machine

成人：`ANNOUNCING → LISTENING_START → SPINNING → MOVING → RESOLVING → TURN_COMPLETE`

小朋友：`ANNOUNCING → LISTENING_START → SPINNING → ASKING_MATH → LISTENING_ANSWER → MOVING → RESOLVING → TURN_COMPLETE`

- `ANNOUNCING`: 使用浏览器中文语音合成播报“已经轮到{玩家名}啦，是否继续？”。
- `LISTENING_START`: 播报结束后再开启识别，避免主持人自己的声音触发指令。
- 识别到“前进 / 开始 / 走吧 / 出发”时进入 `MOVING`。
- 识别到“等 / 等等 / 等一下 / 稍等”时进入等待态，15 秒后只重播一次提醒；玩家也可随时点击前进。
- `ASKING_MATH`: 仅小朋友玩家进入；轮盘停稳后播报“这是多少点？”，此时棋子保持原位。
- `LISTENING_ANSWER`: 接受中文数字“一至六”、阿拉伯数字“1–6”和等价口语；答对后播放鼓励语并进入 `MOVING`，答错则温和提示“再仔细数一数，你一定可以”，继续监听同一道题。
- 语音识别不可用时，小朋友可用屏幕上的 1–6 大数字按钮作答；点击错误数字与语音答错采用同一温和反馈，答对前不移动。
- 未识别、超时、无权限或设备不支持时保持当前回合，并显示“开始前进”“稍等一下”两个大按钮，不自动跳过玩家。
- 购买、升级、卖房、卖地和抵押支持语音导航；所有会改变资金或资产归属的动作必须先复述“对象、金额、结果”，再进入独立确认状态，仅接受当前提示后的“确认/取消”，同时保留屏幕按钮。

## Game Economy

- 默认初始现金为 20,000，可在开局设置中调整为轻松/标准/挑战三档。
- 城市价格和租金按地区分组；租金随房屋等级递增，最高升级为旅馆。
- 当资金不足以购买或升级时禁用对应动作并明确提示。
- 当强制支出造成现金不足时进入“资产自救”界面，展示玩家全部城市、建筑、抵押状态、可回收现金和操作后影响；允许卖房、卖地、抵押与赎回。
- 默认资产自救规则：卖房/旅馆返还原始投入的 50%；无建筑城市可按原价 70% 卖回银行；无建筑且未抵押城市可抵押获得原价 50%，抵押期间不收租，赎回需偿还抵押款的 110%。
- 系统提供三类可解释建议：“最少损失”“最少操作”“优先保留高租金城市”，但不自动执行，最终由玩家按钮或二次语音确认。
- 机会/命运牌单次现金损失设上限：不超过玩家当前现金的 12%，且默认绝对值不超过 1,500。
- 若强制租金或事件导致现金小于 0，触发一次“家庭援助”而不是立即淘汰：自动处置可抵押资产或由银行补到最低生存金；具体数值在实现时配置并通过测试。
- 游戏可按约定轮数结束，也可由家庭手动结束；排名按现金 + 城市购买原价 + 建筑原始投入计算。

## Board and Visual System

- 路线数据参照用户提供的实体棋盘，采用 17×17 外圈的 64 格闭环；主画面使用伪 3D 跟随视角：当前位置采用大尺寸近景卡片，前方 5 站沿透视道路延伸，移动时镜头随棋子逐格推进。
- 主画面右上角不压缩展示 64 个小格，改为信息型路线导航仪：使用五大洲分段进度显示本圈位置，并清晰列出当前地点类型、价格/基础租金或功能说明、归属玩家以及接下来三站。
- 四角为起点、机场/旅行、假日休息和环游奖励；边线混排城市、机会、命运和公共事件格。
- 每个城市格展示城市名、国家/地区、价格、归属颜色与建筑图标。
- 如用户提供实体版图标扫描件，建立本地素材清单并进行统一裁切、透明底和尺寸优化；缺失素材使用原创 CSS 图形或通用表情符号占位。
- 视觉方向为明亮、卡通、温暖的家庭旅行手账，不使用赌场或真实枪械意象；“俄罗斯轮盘”仅表现为彩色数字转盘。

## Casting Mode

- 主目标尺寸为 1920×1080，同时支持 1366×768；核心棋盘在不滚动情况下完整显示。
- 玩家卡片、当前玩家和主要按钮需满足 3 米左右观看距离。
- 提供一键全屏、退出全屏、声音开关和语音开关。
- 右侧导航在投屏优化阶段升级为全员相对位置视图，必须能从远距离比较谁领先、谁落后、相距多少站，并正确处理同格与跨圈情况。
- 窄屏设备保持功能完整，但投屏时以横屏为推荐方向。

## Audio Architecture

- 卡通提示音使用 Web Audio 合成或本地授权音频，不依赖远程 CDN。
- 语音播报使用 Speech Synthesis；中文识别优先使用浏览器 Speech Recognition 实现。
- 首次语音使用前必须由用户点击开启并授权麦克风，以满足浏览器自动播放和权限要求。
- 所有声音提供总开关，语音播报和语音识别提供独立开关。

## Persistence

- 对局状态以版本化 JSON 保存到浏览器本机存储。
- 每个结算动作完成后自动保存；页面重开时提示继续上次对局或新开一局。
- 保留最近的回合事件日志，并提供单步撤销最近一次结算的能力；跨回合撤销需要二次确认。

## Risks / Trade-offs

- 浏览器语音识别支持不一致：使用能力检测和明确的按钮降级，不阻断游戏。
- 投屏环境麦克风通常来自发起投屏的设备，而不是电视：首次开启语音时在界面说明麦克风来源。
- 环境中多人说话可能误触发：只在当前提示结束后的短窗口监听；资金决策采用“指令 → 金额复述 → 再次确认”的两阶段流程，播报期间始终关闭识别。
- 儿童答题被旁人抢答：界面明确提示“请让当前小朋友回答”，但不采集声纹或身份信息；家庭现场由家长协助维持参与感。
- 过多动画会拖慢节奏：移动动画、转账动画均允许点击跳过，且尊重“减少动态效果”系统设置。
