# 环球大富翁 · 界面设计交接

从 `index.html` 开始浏览。目录包含 19 个关键场景，每个场景各有一份手机稿和大屏稿。

## 设备规则

- 开局首页、首页规则、iPhone 安装、恢复存档：手机使用 `390 × 844` 竖屏画布。
- 进入对局后的全部界面：手机使用 `844 × 390` 横屏画布。
- 客厅电视：使用 `1600 × 900` 的 16:9 设计基准。
- 电视适配原则：整张 16:9 游戏画布同时受屏幕宽度和高度约束并等比缩放（`contain`），不拉伸、不裁切；浏览器工具栏或非 16:9 屏幕只会在外围产生背景留边。
- 一屏原则：顶栏、玩家栏、左右 HUD、完整棋盘和中央操作区必须同时落在可视区内；大屏单页隐藏预览切换条，避免任何页面控件遮挡游戏内容。
- 远距可读原则：大屏稿按约 5 米客厅观看距离设置独立字号，正文和操作信息不再沿用手机/电脑端的小字号，关键金额、回合与按钮进一步放大。
- 顶栏、玩家栏、左侧当前玩家 HUD、中央棋盘、右侧旅行动态保持固定的相对位置。

## 视觉方向

- 棋盘恢复为二维环形棋盘，不再使用 3D 跟随视角。
- 配色以深青绿、暖米白、珊瑚红和旅行金为主，地区与事件使用辅助色。
- 字体优先使用系统内的 `Avenir Next / PingFang SC / Microsoft YaHei`，避免外部字体加载影响电视显示。
- 图标采用统一的圆角底板与文字标签，所有重要信息不只依赖颜色表达。
- 主按钮使用实色/渐变高对比样式；次按钮使用白底描边；危险操作必须二次确认。
- 双球俄罗斯轮盘恢复到棋盘中央的回合操作区，位置与原来的核心操作按钮一致；不改变 0–12 双球相加的玩法。

## 文件结构

- `mobile/`：手机预览；开局为竖屏，对局为横屏。
- `large-screen/`：16:9 客厅大屏预览。
- `preview.css`：两端共用的视觉系统和响应规则。
- `viewport.css`：大屏一屏容纳、电视比例与预览导航防遮挡规则。
- 大屏自适应方式：内部始终以完整 `1600 × 900` 排版，根据浏览器真实可视区域计算缩放比例，再由全屏容器整体居中；右边缘与下边缘不会超过屏幕，任何比例都不会让文字单独撑开面板。
- 大屏画布底部固定保留约 `12px` 的外部安全留白，避免棋盘视觉上紧贴电视边缘；留白会参与缩放计算，不遮挡内容。
- 窗口缩小时采用“顶部固定、水平居中”的缩放锚点，不再围绕画布中心向四周收缩；棋盘区域同时减少外围内边距并适度扩大。
- 全部 19 个场景使用同一套画布适配器：大屏为 `1600 × 900`，手机开局为 `390 × 844`，手机对局为 `844 × 390`；宽高同时参与等比缩放，弹窗和 HUD 不会脱离主画布单独变形。
- 棋盘格使用独立的样式命名，避免“机会格/起点格”误用同名弹窗或首页按钮样式而被压窄、撑高。
- `preview.js`：静态场景内容；不连接游戏状态，不会修改正式玩法。
- `generate.mjs`：重新生成全部薄 HTML 入口。

这些文件是独立的静态设计稿，不会改动正式游戏逻辑、存档或功能。
